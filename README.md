# Stitch Sheets

Open-core **service plugin** for [Stitch Manager](https://github.com/StitchWB/Stitch-Manager):
the **Identity Graph** backed by Google Sheets — reads/writes account, profile, and auth-method
links in a Google Spreadsheet, with service-account JWT or OAuth auth.

- **Kind:** `service` (plugin id `stitch-sheets`, service `google_sheets`)
- **Runtime:** spawned by the Stitch `ServicePluginHost` as `python -m stitch_sheets`, speaks
  JSON-RPC 2.0 (vendored `RpcPluginServer`) plus reverse RPC (`call_host`) for OAuth operations
- **Self-contained:** no `stitch_backend` imports; owns a SQLite cache of sheet snapshots. Auth is
  service-account JWT (self-contained) or OAuth tokens obtained from the host via reverse RPC.

## Commands

`test_connection`, `fetch_dataset`, `init_schema`, `upsert_link`, `delete_link`,
`upsert_account_link`, `delete_account_link`, `upsert_profile_link`, `delete_profile_link`,
`upsert_auth_method`, `delete_auth_method`, `upsert_account_auth_link`,
`delete_account_auth_link`, `start_oauth`, `exchange_oauth_code`.

## Layout

```
plugin.json              manifest (schema v2, declarative UI + i18n + commands)
stitch_sheets/
  __main__.py            JSON-RPC entry point (RpcPluginServer + reverse RPC)
  service.py             Google Sheets API client (JWT + OAuth)
  storage.py             SQLite snapshot cache
  _vendor/rpc_server.py  vendored RpcPluginServer (regenerated by stitch_plugin_tools; do not edit)
```

## Development

```bash
pip install ruff
ruff check .
```

Integration tests for this plugin live in the private Stitch monorepo (they need the Stitch SDK
and plugin host). This repo's CI runs lint + compile checks; the monorepo runs the full
plugin-vs-core integration suite against the mirrored copy.

## Distribution

This plugin is **signed and distributed via the Stitch gated server** — the signing key lives in
the private hub, never in this repo. Released packages are assembled from this source, signed in
the hub, and published to the distribution server for entitled users.

## Contributing

External contributions are welcome — open a PR against this repo. Keep changes within the plugin
(no new `stitch_backend` imports, keep the package self-contained). The vendored
`_vendor/rpc_server.py` is regenerated from the core SDK — do not edit it by hand.
